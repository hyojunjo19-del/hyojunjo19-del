コペンハーゲンを拠点とするシステムエンジニアおよびオーディオDSPアーキテクトです。  
超低遅延デジタル信号処理、ハードリアルタイムオーディオランタイム、音響機器向け組み込みファームウェアの開発に注力しています。

- 🔭 現在開発中: **prism-dsp** (C++20 SIMDオーディオ合成エンジン)、**iron-synth** (Rustベースのベアメタル・ポリフォニック音源コア)。
- ⚙️ 日常的な技術焦点: リアルタイムオーディオパイプライン、ロックフリー・リングバッファ、Linux ALSAカーネルサブシステム、ヒープ割り当てゼロ(Zero-Allocation)のDSPアルゴリズム。

## 主なオープンソースプロジェクト

### `prism-dsp`
> 厳格なハードリアルタイム制約を満たすよう設計された、ヘッダーオンリー(Header-Only)のC++20オーディオDSPフレームワークです。

- **技術スタック**: C++20, AVX2 / ARM NEON ベクトル組み込み関数, CMake
- **主な特徴**:
  - オーディオ処理メインループ(`processBlock`)内での動的ヒープメモリ割り当てを完全に排除。
  - SIMDベクトル化されたバイクアッド(Biquad)フィルターカスケード、非線形飽和のための高速多項式近似、帯域制限オシレーター合成。
  - サブサンプル精度のインパルス応答および周波数応答検証を含むユニットテストスイートを内蔵。

### `iron-synth`
> ARM Cortex-M7マイクロコントローラー専用にRustで記述されたベアメタル・ポリフォニックシンセサイザーコアです。

- **技術スタック**: Rust (`no_std`), Cortex-M アーキテクチャ, I2S オーディオインターフェース
- **主な特徴**:
  - MIDIトリガーからDAC出力まで、予測可能で1ミリ秒未満のエンドツーエンド低遅延を実現。
  - 512KBの密結合メモリ(TCM)を直接制御し、バッファレンダリング中のキャッシュミスを原理的に排除。
  - エイリアシングを抑えたマルチ波形オシレーター、インテリジェントなボイススティーリング、仮想アナログ・ラダーフィルターエミュレーションを搭載。

### `alsa-jitter-probe`
> ALSAオーディオバッファのアンダーラン(xruns)やスケジューリング遅延スパイクを診断するためのLinuxカーネルリアルタイムeBPFツールチェーンです。

- **技術スタック**: C, eBPF (bpftrace, libbpf), Python
- **主な特徴**:
  - カーネルスケジューラーのコンテキストスイッチ地点およびALSA DMAバッファポインタに直接フック。
  - 割り込みサービスルーチン(ISR)遅延、DPC遅延、スレッドプリエンプション待ち時間をリアルタイムにマイクロ秒単位で定量化。
  - オーディオランタイムに負荷をかけずに、フレームグラフおよびヒストグラムテレメトリを生成。

## エンジニアリング哲学

1. **決定論的実行の最優先 (Deterministic Execution First)**: リアルタイムオーディオにおいて、遅れて届いたサンプルはドロップされたサンプルと同じです。オーディオスレッドは決してブロックせず、ヒープメモリを確保せず、ミューテックスを触らず、ファイルやネットワークのI/Oを行いません。
2. **第一原理に基づくメモリ配置 (First-Principles Memory Layout)**: CPUキャッシュのヒット率がDSPのスループットを左右します。抽象化の層よりも、配列の構造体(Structure-of-Arrays)、メモリアラインメント、予測可能な分岐パターンを常に優先します。
3. **再現性のある音質基準 (Reproducible Sound Quality)**: フィルター方程式とスペクトル解析の数学的厳密性は、44.1 kHzから192 kHzまでのすべてのサンプリングレートにおいて実機ハードウェアの測定結果と一致する必要があります。
4. **最小限の外部依存 (Minimal External Footprint)**: 外部依存関係の変動に左右されず、自立的で監査可能、保守性の高いコードベースを維持します。
