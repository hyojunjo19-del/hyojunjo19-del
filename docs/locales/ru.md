# Мартин Хольст (Martin K. Holst)

Системный инженер и архитектор цифровой обработки сигналов (DSP) из Копенгагена.  
Специализируюсь на низколатентной обработке звуковых сигналов, средах жесткого реального времени и встроенном микропрограммном обеспечении для музыкального оборудования.

- 🔭 Текущая разработка: **prism-dsp** (библиотека синтеза звука на C++20 с поддержкой SIMD) и **iron-synth** (полифонический синтезатор на Rust для голого железа).
- ⚙️ Ежедневные технические задачи: Аудиоконвейеры реального времени, неблокирующие кольцевые буферы (lock-free), подсистема ALSA ядра Linux и DSP-алгоритмы с нулевым динамическим выделением памяти (zero-allocation).
- 💬 Темы для обсуждения: Точность вычислений с плавающей запятой, задержки буферов аудиодрайверов, фазовые вокодеры, численное моделирование аналоговых схем и модульные синтезаторы.
- ⚡ Личные особенности: Измеряю аудиоджиттер в микросекундах, коллекционирую винтажные микросхемы аналоговых фильтров, завариваю спешелти кофе пуровер с контролем минерального состава воды и езжу на велосипеде против порывистого датского прибрежного ветра.

## Избранные проекты с открытым исходным кодом

### `prism-dsp`
> Высокопроизводительный фреймворк аудио-DSP на C++20, состоящий исключительно из заголовочных файлов (`header-only`) и рассчитанный на условия жесткого реального времени.

- **Стек**: C++20, векторные интринсики AVX2 / ARM NEON, CMake
- **Ключевые особенности**:
  - Полное исключение динамических выделений памяти из кучи внутри основного цикла обработки звука (`processBlock`).
  - SIMD-векторизованные каскады биквадратных фильтров, быстрые полиномиальные аппроксимации для нелинейного насыщения и синтез полосно-ограниченных генераторов.
  - Исчерпывающий набор модульных тестов с проверкой импульсной и частотной характеристик на субсэмпловом уровне.

### `iron-synth`
> Движок полифонического синтезатора для микроконтроллеров ARM Cortex-M7, написанный на Rust для работы без операционной системы (`no_std`).

- **Стек**: Rust (`no_std`), Архитектура Cortex-M, Аудиоинтерфейс I2S
- **Ключевые особенности**:
  - Предсказуемая сквозная задержка менее 1 миллисекунды от срабатывания события MIDI до аналогового выхода ЦАП.
  - Прямое управление 512 КБ тесно связанной памяти (TCM), гарантирующее отсутствие кэш-промахов при рендеринге буферов.
  - Осцилляторы с подавлением алиасинга, интеллектуальное распределение голосов и эмуляция аналогового транзисторного лестничного фильтра.

### `alsa-jitter-probe`
> Набор инструментов eBPF для ядра Linux, предназначенный для диагностики опустошения буферов ALSA (xruns) и всплесков задержек планировщика.

- **Стек**: C, eBPF (bpftrace, libbpf), Python
- **Ключевые особенности**:
  - Подключение непосредственно к точкам переключения контекста планировщика и указателям буфера ALSA DMA.
  - Измерение задержек обработчиков прерываний (ISR), латентности DPC и времени вытеснения потоков в реальных микросекундах.
  - Построение флеймграфов и телеметрии в виде гистограмм без создания вычислительных накладных расходов для аудиопроцесса.

## Инженерные принципы

1. **Детерминированное исполнение превыше всего (Deterministic Execution First)**: В звуке реального времени опоздавший сэмпл ничем не отличается от потерянного. Аудиопоток ни при каких обстоятельствах не должен блокироваться, выделять память в куче, захватывать мьютексы или выполнять операции ввода-вывода.
2. **Организация памяти от первых принципов (First-Principles Memory Layout)**: Коэффициент попадания в процессорный кэш определяет реальную пропускную способность алгоритмов. Структуры массивов (Structure-of-Arrays), выравнивание в памяти и предсказуемые ветвления важнее многослойных абстракций.
3. **Воспроизводимая акустическая точность (Reproducible Sound Quality)**: Математическая строгость уравнений фильтрации обязана точно совпадать с физическими измерениями аппаратных эталонов на всех частотах дискретизации от 44.1 до 192 кГц.
4. **Минимальная внешняя связность (Minimal External Footprint)**: Кодовая база должна оставаться самодостаточной, прозрачной для аудита и не подверженной рискам внезапной поломки внешних зависимостей.
